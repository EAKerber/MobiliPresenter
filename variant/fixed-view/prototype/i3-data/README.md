# I3 data

Esta pasta contém apenas geometria e política de **apresentação** para a câmera fixa.

- `calibration.json`: posições aparentes, confiança e evidência.
- `visual-layers.json`: slots de overlays realistas e fallbacks estruturais.

Nenhum valor de coordenada em pixels desta pasta pode ser convertido automaticamente em cota de fabricação. A única medida métrica global usada pelo protótipo é o envelope de parede de 3550 mm, sem escala pixel→mm.
